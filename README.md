# Substation Modeling — тренажёр сборки подстанции 110 кВ

Дипломный проект: 3D-песочница на Unity, в которой электромонтёр собирает открытое
распределительное устройство подстанции 110 кВ из готового оборудования, соединяет
его проводами и проверяет свою схему по эталону, сохранённому преподавателем.

## Возможности

- **Библиотека оборудования** — выключатели, разъединители, трансформаторы тока и
  напряжения, силовые трансформаторы, блоки ОПН/ЗОН, ошиновка. Поиск по названию,
  сворачиваемые категории, установка на сцену перетаскиванием (drag & drop) с
  полупрозрачным превью.
- **Собственный runtime-гизмо** — перемещение, поворот и масштаб (`T` / `R` / `Y`),
  привязка к шагу по `Ctrl`, отмена по `Esc`/ПКМ. Инспектор с числовыми полями и
  «протягиванием» значений мышью.
- **Провода** — соединение точек подключения с провисанием по параболе (аппроксимация
  цепной линии). Выбор точки учитывает размер маркера на экране и перекрытие
  другими объектами.
- **Проверка по эталону** — преподаватель сохраняет правильную схему (режим
  «Тренировка» или «Экзамен» с паролем), ученик загружает её и видит результат:
  верные провода — зелёные, лишние — красные, недостающие — мигающие оранжевые.
  Все попытки записываются в защищённый от правки журнал.
- **Сохранение проекта** — оборудование, провода и положение камеры в зашифрованный
  файл с проверкой целостности (AES-256 + HMAC-SHA256).
- **Локализация** — все тексты интерфейса, включая встроенную справку, лежат в
  `StreamingAssets/Localization/*.lang` (сейчас русский и английский). Язык
  переключается на лету, а новый язык добавляется без пересборки.

## Технологии

- Unity **6000.4.2f1** (Unity 6), Universal Render Pipeline
- C#, Input System, uGUI + TextMeshPro
- System.Security.Cryptography: AES, HMAC, PBKDF2

## Запуск

1. Клонируйте репозиторий и откройте папку в Unity Hub (версия 6000.4.2f1).
2. Откройте сцену `Assets/Scenes/SampleScene.unity` и нажмите **Play**.
3. Справка по всем функциям открывается в программе по `Ctrl+O`.

## Управление

| Действие | Клавиши |
|---|---|
| Осмотреться / двигаться | ПКМ + мышь / `W A S D`, `Q`/`E`, колесо, `Shift` — быстрее |
| Режимы: объекты / провода / удаление проводов | `1` / `2` / `3` |
| Перемещение / поворот / масштаб | `T` / `R` / `Y` (`Ctrl` — с шагом) |
| Удалить выделенный объект | `Del` |
| Сохранить / сохранить как / открыть | `F5` / `Shift+F5` / `F9` |
| Проверка по эталону | `F2` |
| Справка | `Ctrl+O` |

## Архитектура

Весь код находится в `Assets/PlacementSystem` (пространство имён `PlacementSystem`):

```
Scripts/
  Core/             PlacementManager, SelectionManager, EditorModeManager,
                    InteractionLock (общие блокировки ввода), InputUtility
  Data/             ScriptableObject-описания оборудования и категорий
  Drag/             перетаскивание оборудования из библиотеки на сцену
  Manipulation/     runtime-гизмо и его отрисовка
  EnergyConnector/  точки подключения, провода, режимы соединения и удаления
  Check/            сравнение схемы с эталоном, шифрование файлов, журнал
  Save/             сохранение и загрузка проекта
  Localization/     загрузка .lang-файлов и локализованные тексты
  UI/               панели, инспектор, справка, строка состояния
Editor/             пункты меню «Placement System»: настройка сцены,
                    генерация интерфейса, улучшение графики
```

Основные решения:

- Системы общаются через события (`ObjectSpawned`, `SelectionChanged`,
  `ModeChanged` и др.), а не напрямую.
- `InteractionLock` — единое место, которое решает, кому сейчас принадлежит ввод:
  камере, гизмо, полю ввода или модальному окну.
- Интерфейс не собирается вручную: его целиком генерирует
  `Placement System ▸ Rebuild UI` (`Editor/PlacementUIBuilder.cs`), цвета задаются
  в `UI/UITheme.cs`.
- Подсветка объектов и проводов сделана через `MaterialPropertyBlock`, поэтому
  материалы не копируются.
- Точки подключения определяются по индексу внутри префаба, поэтому эталон не
  зависит от расположения объектов на сцене.

## Ограничения

- Провода только визуальные: электрическая модель (токи, напряжения) не
  рассчитывается.
- Ключ шифрования файлов встроен в программу. Он защищает файлы от случайного
  просмотра и правки, но не от того, кто разберёт исходный код. Пароль экзамена
  хранится только в виде хеша PBKDF2.
- Диалоги открытия и сохранения файлов используют WinAPI, поэтому полностью
  поддерживается только Windows.
